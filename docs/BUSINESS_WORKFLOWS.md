# 账单、价格、备份与日常业务

更新日期：2026-09-30。2026-09-21 版本新增库存台账、客户档案、收款登记、备份与恢复四个页面；2026-09-30 新增退胚、返工出货、批次校验和“对账与打印”页面，入库改为不计金额。

## 推荐使用顺序

1. 在 **客户档案** 中维护名称、联系人、电话、地址和账期。
2. 在 **辅助价目** 中创建物料、设置价格和生效日期。
3. 录入 **入库明细**（收货或客户退货，填写加工单号），然后录入 **出货明细**：成品出货自动扣库存并建立应收账单；退胚、返工出货选择原批次，免费。
4. 在 **对账明细** 查看未收余额，点击“收款”登记该账单的实际到账金额。
5. 在 **对账与打印** 按客户和月份生成对账单，或打印出货单、退胚单交给客户签收。
6. 在 **库存台账** 查看余额、流水、安全库存、库位并进行盘点。
7. 管理员定期查看 **备份与恢复**，并将备份下载至其他设备。

## 账单规则

- 一张出货记录绑定一张账单，开立后不可改绑；账单保存数量、开单价、金额、客户名称和客户 ID。
- 后续价目和客户改名不会改写历史账单价格或名称。
- 无收款的有效账单允许修正原出货数量，金额按账单原单价计算；改业务日期时沿用原账期移动到期日。
- 有收款或历史结清金额时，关联出货记录不可修改或撤销。要纠错，先作废错误收款；历史结清标记只能由管理员填写原因撤销。
- 账单的“删除”接口改为 **作废**，必须填写原因；保留原记录，服务重启不会重新生成。有效收款未撤销前不能作废账单。
- 作废账单不计入应收、客户余额和月度应收。可以恢复原账单，仍保留开单价格。
- 撤销出货时库存回退，关联账单作废留档；已撤销出货的账单不能单独恢复。
- 出入库撤销为逻辑撤销，保留原数据和库存冲正流水；撤销入库后若库存不足，整个操作拒绝执行。
- 补建账单只能选择没有任何账单（包括作废账单）的有效出货记录。
- 对账页支持客户、日期、状态、逾期筛选和筛选结果导出，操作记录可查看作废、恢复、收款和修改原因。

## 价格规则

- 指定业务日期的适用价格：该物料所有 `生效日期 ≤ 业务日期` 的记录中，日期最新的一笔；同日多条以最后保存的修订为准。
- 当前价目按系统业务日计算，未来价目显示“待生效”，历史补价不覆盖更晚的已生效价。
- 修改价目追加历史；删除一条价目后重新选取剩余已生效价格。不存在已生效价时显示 0 和“暂无生效价目”。
- 新单默认按业务日期取价；业务日期没有有效价格（包括完全没有价目、只有未来价目）时拒绝开单，避免静默开出零价账单。显式指定的零单价仍作为合法开单价保留。
- 金额 = 数量 × 单价，按分四舍五入（例如 0.5 × 0.73 = 0.37）；各类汇总按分累加。
- 已保存单据保持开单价；出入库和改单不会改写物料标准价。
- 物料信息和价目通过一个事务保存，校验失败不会留下半成品物料。
- 默认业务时区为 `Asia/Shanghai`，可通过 `FACTORY_BUSINESS_TIMEZONE` 指定有效 IANA 时区，例如 `Asia/Dubai`。前端业务日期与服务端一致，ISO 操作时间仍以 UTC 保存。
- 到期价目在下一次读取或开单时自动生效，无需重启服务。

## 业务类型与批次

实际业务流程为：**收货 → 退胚（部分胚料原样退回）→ 加工 → 出货 → 客户退货 → 返工出货**。加工本身不在系统中登记。

| 页面 | 业务类型标签 | 归类 | 库存 | 金额 / 账单 |
| --- | --- | --- | --- | --- |
| 入库明细 | 正常入库 | 收货 | + | 不计金额 |
| 入库明细 | 退胚回库 | 收货 | + | 不计金额 |
| 入库明细 | 不良退回 | 客户退货 | + | 不计金额 |
| 出货明细 | 成品出货 | 出货 | − | 按开单价计加工费，自动生成应收账单 |
| 出货明细 | 退胚 | 退回收货 | − | 免费，不生成账单 |
| 出货明细 | 返工出货 | 退货返工后送回 | − | 免费，不生成账单 |

- 六个标签原样保存，经营分析按标签分别统计数量。“正常入库”和“退胚回库”在批次计算中都算收货。
- 入库不计单价和金额：新录入或修改的入库记录单价、金额一律为 0。2026-09-30 之前录入的入库金额保留在数据库中，但报表不再使用。

**批次**

- 加工单号只跟“加工单号”自己的编码规则：设为自定义输入时，入库也可以手填客户的原加工单号，不受送货/回库单号规则影响。
- 一个批次 = 同一客户 + 同一物料 + 同一加工单号。退胚和返工出货必须选择已有批次，不能手填新加工单号；入库时请填写加工单号，否则后续无法对应。
- 退胚：批次内始终要满足 **退胚合计 ≤ 收货 − 成品出货**。录入时表单显示本批次收货、已出货、已退胚和本单最多可退数量。
- 返工出货：批次内始终要满足 **返工出货合计 ≤ 不良退回**。
- 这两条规则在每次新增、修改、撤销后都会重新检查，不只在录入退胚时检查。例如某批次已有退胚后，再多出成品、减少或撤销收货导致超出时，操作会被拒绝并提示超出数量；需要先调整或撤销退胚。
- 没有退胚的批次不限制成品出货数量，只受物料总库存约束；没有返工出货的批次不限制不良退回数量。
- 保存后，成品出货、退胚、返工出货之间不能互相修改类型，需要撤销后重新登记。修改和撤销照常联动库存。
- 退胚和返工出货不能手动补建账单，对账明细补建账单时也不会列出。

## 对账单与出货/退胚单打印

入口：导航“对账与打印”；也可从对账明细的“生成对账单”、出货明细的“打印 / 打印所选”跳转，筛选条件会带过去。

**三种单据**

| 单据 | 取数范围 | 分单 |
| --- | --- | --- |
| 客户对账单 | 所选客户在日期范围（按送货日期，含首尾）内的 **有效应收账单**，包含已结算的；数量、单价、金额取开单快照；退胚和返工出货不计入，也不提示“未开账” | 一个客户一张，标题为“YYYY年M月对账单”（整月时）或“开始 至 结束 对账单” |
| 出货单 | 该客户范围内未撤销的成品出货和返工出货记录 | 按客户 + 出货日期 + 送货单号 + 类型分单；同一单号跨日期不合并；返工出货单标题为“出货单（返工）” |
| 退胚单 | 该客户范围内未撤销的退胚记录 | 分单规则同出货单，使用退胚表头和“审核”签字栏 |

**使用步骤**

1. 选单据类型、客户和日期（可用“快捷月份”一键选整月），点“查询明细”。
2. 核对明细并勾选要打印的记录（可用“全选”）。只打印部分记录时，合计按所选记录计算并标明“所选明细合计”。
3. 设置纸张规格、页边距、制表人和制单日期，点“生成打印预览”。
4. 在预览中直接打印，或点“导出 Excel”得到带格式的 `.xlsx`。

**规则与提示**

- 对账单会提示本期“尚未开账”的出货和“已作废”的账单，它们不计入对账金额；需要时先在对账明细补建或恢复账单。
- 本期有非 RMB 账单时拒绝合并对账。金额以“分”累加，避免浮点误差。
- 按客户 ID 归集，客户改名后历史记录仍在同一客户下，单据抬头显示当前客户名。
- 勾选的记录如果在查询后被撤销、改日期或不属于当前客户/类型，生成时会要求重新查询；一次最多 2000 条。
- 出货单和退胚单每页 8 行明细，超出自动分页并标注“第 N / M 页”，右侧印有四联颜色说明（存根白、客户红、仓库黄、采购蓝）。

**纸张规格**

- 预置：241 mm 连续纸二等分（139.7 mm 高，出货/退胚默认）、三等分、整张；190 mm 窄幅二等分、整张；A4 横向（对账单默认）、A4 纵向、A5 横向；也可自定义。
- 自定义范围：纸宽 120–420 mm、纸高 80–600 mm、页边距 0–20 mm。连续纸按撕线后的单张尺寸填写。
- 打印时在打印机驱动中选择相同尺寸的纸张，缩放设为 100%，关闭浏览器页眉页脚。纸张设置保存在当前浏览器。

**公司抬头**

- 公司名称、地址、电话、邮箱、传真，以及对账单说明和出货/退胚单说明，保存在业务库 `app_settings` 中，所有设备共用，随业务备份一起备份和恢复。
- 仅管理员可在该页面点“修改公司抬头”编辑；公司名称不能为空，说明文字最多 1500 字。未设置时使用代码内置的默认抬头。

## 库存台账

- 库存余额包括编码、规格、单位、当前库存、安全库存和库位；可搜索和只看低库存。
- 流水记录期初、入库、出库、改单、撤销、盘点差异，以及操作后的结余、关联单号、原因和操作人。
- 升级时用当前实际库存生成一条“期初结转”，不根据不完整的旧记录反推历史库存。此前业务仍在出入库明细中查询。
- 流水按登记顺序排列；业务日期可能补录，流水结余反映登记当时的库存，不表示按业务日期重算后的余额。
- 盘点要求实盘数量和原因，服务端检查盘点前库存是否已变化；多人同时操作时不会用旧盘点值覆盖新库存。
- 数量最多保留六位小数，出入库和盘点都可录入小数；余额和流水可导出 Excel。
- 库存数只由出入库单据和盘点改变；修改物料资料（规格、安全库存、库位等）不会改动库存。
- 有库存或数量变动记录的物料不允许删除或改变计量单位，避免改变历史流水的含义。

## 客户档案

- 名称不允许重复，支持联系人、电话、地址、账期、备注以及启用/停用。
- 升级时将已有业务中的客户名称归入档案，空白联系方式需要补全。
- 出入库必须选择已有的客户档案；系统不会按名称自动新建客户，新客户请先在客户档案中新增。入库选加工单号时会带出该批次的客户和物料。
- 修改单据时默认保持原客户；入库与出库之间不能互改类型，需要撤销后重新登记。
- 新账单到期日为出货日期加客户账期。调整账期不改变既有账单。停用客户前会弹窗确认。
- 改名保留历史单据名称，但仍通过客户 ID 归集往来；停用阻止后续新单，不影响查询和收款。
- 客户页显示累计有效应收、本系统实收、历史结清及未收余额的汇总数据，页面突出应收和余额，并可跳转该客户对账。

## 收款登记

- 一笔收款关联一张有效应收账单，支持多次部分收款；不接受超过剩余余额的款项。
- 记录实际到账日期、金额、方式、银行流水/凭证号、备注和登记人。日期不能早于开单日期或晚于业务当天。
- 金额以整数“分”保存，避免浮点累计误差；重复网络请求使用同一请求标识，防止重复登记。
- 状态自动计算为未结清、部分收款、已结算；已作废单据单独显示。零金额账单自动结清。
- 录错的收款填写原因作废，恢复对应账单余额并保留流水，不能直接抹掉原记录。
- 升级前的已结清账单保留为 **历史结清金额**，不伪造银行到账日期或收款方式，不计入“本系统登记实收”。
- 本期不包含客户预付款、退款、一次收款分摊多张账单、应付付款或银行接口对接。

## 备份与恢复

- 仅管理员访问。备份范围是完整业务库，包括物料、价目、出入库、账单、客户、收款、库存流水、账单操作记录和编号设置。
- **不包含认证库 `auth/auth.db`**；恢复业务备份不会改变账号或登录状态。需要整机迁移时另行保存认证库。
- 使用 SQLite 在线备份生成一致快照，支持手动备份、下载、上传 `.db`（最大 100 MB）、自动备份设置和恢复。
- 默认启动后备份，此后每 24 小时检查执行一次到期备份；保留最近 14 份自动备份。间隔可设 1–168 小时，保留 1–90 份。
- 手动、上传、升级前、恢复前保护副本不受自动清理影响。自动设置位于 `backups/settings.json`，不随业务库恢复覆盖。
- 备份文件权限为仅服务账号可读写；文件名由系统生成，接口不接受任意磁盘路径。
- 上传和恢复校验 SQLite 完整性、版本与必要字段，拒绝非业务库、未来版本、视图和触发器。
- 恢复须输入“恢复业务数据”，先保存保护副本，再替换数据库并运行兼容迁移。失败时尝试回退到保护副本。
- 恢复期间暂停业务写入；恢复前通知同事停止录入，完成后刷新所有浏览器。
- 首次升级旧业务库前自动创建升级保护副本；备份失败则停止升级。业务重置也会先保存保护副本。
- 本机备份不能覆盖整台服务器损坏的场景，应定期下载并复制到其他设备。服务停止期间不执行自动任务，重新启动后补做已到期的备份。
