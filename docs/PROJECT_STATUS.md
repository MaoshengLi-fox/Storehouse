## 2026-09-30 全系统测试后的修复

测试方式：浏览器按真实流程走完 13 个页面（含手机尺寸），后端随机压力测试（数千次随机增改撤、收款、作废，每步核对库存、批次、账单一致性），加独立代码审阅。核心库存/批次/账单逻辑未发现错误，以下问题已修复。

| 类别 | 问题 | 修复 |
| --- | --- | --- |
| 安全（高） | 请求头或路径格式不对时，未登录也能让服务进程退出 | URL 解析移入错误捕获并使用固定基址；增加进程级兜底日志 |
| 数据 | 不选客户也能录单，价目“厂商”名被自动建成客户（出货还会给它开账单） | 前端必须选客户档案且不再用厂商名填客户；后端不再按名称自动新建客户 |
| 数据 | 在库存台账改安全库存/库位会把品名改成规格 | 未提供品名时保留原品名 |
| 数据 | 物料修改接口可直接写库存，绕过盘点校验 | 库存只能由出入库单据和盘点改变 |
| 数据 | 没有价格时静默开出 0 元“已结算”账单；入库改成出库沿用 0 价 | 无有效价格拒绝开单（显式 0 价仍允许）；入库与出库不能互改类型 |
| 数据 | 金额舍入少一分（0.5 × 0.73 = 0.36） | 按分四舍五入（0.37）；汇总按分累加，不再出现 0.30000000000000004 |
| 安全 | 重置密码后旧会话仍有效；登录无限流；同步哈希阻塞服务；密码首尾空格不一致 | 重置/停用时注销该用户会话；同账号同 IP 失败 5 次锁 15 分钟（账号总计 20 次）；异步哈希、恒定耗时比较；登录同样去除首尾空格 |
| 安全 | 管理员可通过接口停用自己或最后一个管理员 | 均拒绝 |
| 接口 | 业务校验失败统一返回 500，并暴露内部错误 | 校验失败 400、未登录 401、无权限 403、冲突 409、限流 429；内部错误只返回通用提示并写日志 |
| 接口 | `/api/health` 未登录返回数据库路径；普通用户 bootstrap 含服务器路径 | health 只返回状态；路径只给管理员 |
| 规则 | 送货/回库单号设为自动后，入库加工单号被强制自动生成 | 加工单号只跟加工单号自己的编码规则 |
| 规则 | 客户改名后接口改单不带客户编号会分裂出新客户 | 改单默认保持原客户 |
| 其他 | 作废收款后同一请求标识重放“成功”；字符串 `'false'` 被当成启用；价目可改挂到别的物料；月度出货金额含作废账单 | 分别拒绝重放、按字面解析布尔、禁止换物料、按有效账单统计 |

体验优化：入库选加工单号带出客户；入库、出货数量支持小数并提示非法值；制表人默认当前用户并标必填；表格列按“日期、类型、客户、加工单号、物料、数量”排在前面，“厂商”列改称“客户”，出货表增加金额列；手机上操作列不再固定遮挡内容；打印预览在手机上自动缩放；批次报错区分“正在录退胚”和“修改其他单据导致超出”；已撤销出货的作废账单不再显示“恢复”；撤销提示统一为“已撤销”；用户管理和库存流水时间显示为本地时间；导出文件用中文名；出货/退胚单抬头显示电话；表单弹窗按 Esc 不再丢失内容；停用客户需确认；普通用户进管理页有提示；业务日期晚于今天有提醒；经营分析补齐无数据月份、刻度取整带 ¥；账单导出增加账单编号和客户列；未填分类显示“未分类”。

新增文件：`server/errors.js`（错误到 HTTP 状态码的映射）、`src/composables/useWideScreen.js`、`tests/fixes.test.js`（10 项回归测试）。部署配置 `deploy/nginx-factory.conf` 增加 `X-Real-IP`，登录限流按真实 IP 计算，更新站点时需同步并重新加载 Nginx。

## 2026-09-30 业务类型与批次规则

| 模块 | 交付内容 |
| --- | --- |
| 业务类型 | 保留入库三标签（正常入库、退胚回库、不良退回）和出库三标签（成品出货、退胚、返工出货）；新增“返工出货”；非列表内的新标签被拒绝 |
| 入库不计金额 | 入库单价、金额一律为 0；导出和单条打印不再显示入库单价/金额；历史入库金额保留但报表不使用 |

| 返工出货免费 | 须选原退货批次，返工出货合计 ≤ 不良退回；不开账单、不进对账单；打印为“出货单（返工）” |
| 经营分析 | 去掉入库金额和“出入库金额差”；改为月度成品出货金额和按六个标签的月度数量 |
| 代码位置 | 新增 `shared/businessTypes.js`；修改 `server/database.js`、`server/documents.js`、`server/documentExport.js`、出货/入库/对账/经营分析页面、`src/utils/printDocuments.js`、`src/utils/exporters.js`、`src/lib/desktopApi.js` |
| 测试 | 新增 `tests/batches.test.js`（5 项）；`tests/documents.test.js` 中退胚相关用例改为先登记收货 |

## 保留的前轮修复

- 修改价目不清空库存、安全库存和库位。
- 自动物料编码允许不输入编码。
- 历史账单保留开单价格，零单价不会被当前价目替换。
